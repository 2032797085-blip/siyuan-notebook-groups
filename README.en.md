# SiYuan Notebook Groups

[简体中文](./README.md)

Introduction
Notebook Groups adds notebook grouping to SiYuan’s native document tree, allowing you to organize notebooks directly in both the desktop app and the mobile native document tree.
You can group notebooks, drag them into categories, reorder them freely, and create a clear “Group → Notebook → Document” hierarchy without merging notebooks or moving original documents.
Key Features
- Group Management: create, rename, delete, expand, and collapse groups
- Drag to Group: drag notebooks into target groups
- Free Ordering: reorder groups and notebooks inside each group
- Quick Create: create a new notebook directly inside a group
- Native Tree Integration: works directly inside SiYuan’s native document tree
- Mobile Support: available in Android / iOS native document tree
- Auto Save: grouping and order are preserved after restart
- Ungrouped Section: ungrouped notebooks are collected under “Ungrouped Notebooks”
- Non-destructive: only changes organization and display, not your original notebook/document data
