# 思源笔记本分组管理

[English](./README.en.md)

简介
思源笔记本分组管理 为思源笔记原生文档树提供「笔记本分组」能力，支持在 桌面端 与 移动端原生文档树 中直接对笔记本进行分组、拖拽归类和自由排序。
无需合并笔记本，也不需要移动原始文档，即可实现清晰的 「分组 → 笔记本 → 文档」 层级管理，让笔记本整理更直观、更高效。
主要功能
- 分组管理：创建、重命名、删除、展开/收起分组
- 拖拽归类：将笔记本拖入目标分组
- 自由排序：支持调整分组顺序，以及组内笔记本顺序
- 快速新建：可在分组内直接新建笔记本
- 原生树集成：直接整合到思源原生文档树，无需额外分组面板
- 移动端支持：Android / iOS 原生文档树可直接使用
- 自动保存：分组关系与排序自动保存，重启后继续生效
- 未分组集中显示：未归类笔记本统一显示在「未分组笔记本」下
- 不修改原始数据：仅改变组织展示方式，不破坏原始笔记本与文档结构
