# 思源笔记本分组管理

[English](./README.en.md)

**为思源笔记原生文档树增加「笔记本分组」功能。** 通过类似文件夹的分组集中整理多个笔记本，直接呈现 **「分组 → 笔记本 → 文档」** 的层级结构，无需合并笔记本，也不需要移动原有文档。

## 主要功能

- **直接整合到原生文档树**：无需额外打开独立的分组面板。
- **自定义分组**：支持新建、重命名、删除、展开和收起分组。
- **分组内新建笔记本**：点击分组标题右侧 **＋**，立即创建真实笔记本并自动归入该分组。
- **分组拖拽排序**：按住分组标题前的 **⠿** 手柄拖动，可以改变整个分组的先后顺序。
- **手机原生文档树分组（测试版）**：在手机「文档」面板里直接显示「分组 → 笔记本 → 文档」，保留思源原生的文档展开和打开操作。
- **拖拽归组**：按住笔记本旁的 **⠿ 手柄**，将笔记本拖入目标分组。
- **自由排序**：可将笔记本拖到同组其他笔记本的上方或下方，指定显示位置。
- **自动保存**：保存分组关系、分组折叠状态与笔记本顺序，重启后继续使用。
- **未分组区域**：尚未归类的笔记本集中显示在「未分组笔记本」下。
- **不修改笔记数据**：分组只是界面上的组织方式；删除分组不会删除其中的笔记本和文档。

## 使用方法

1. 在思源笔记中启用「笔记本分组管理」插件。
2. 在原来的文档树中点击「管理分组」，创建需要的分组。
3. 按住笔记本名称旁的 **⠿ 手柄**，将笔记本拖到分组名称或分组内指定位置；拖动时会出现目标位置提示。
4. 点击分组名称可展开或收起；分组右边「＋」可新建笔记本，左边「⠿」可拖动分组顺序。
5. 手机端在思源原生「文档」面板查看分组；长按 ⠿ 手柄约 0.3 秒开始拖动。点击「管理分组」可新建／重命名／删除分组，或手动调整笔记本归属。

## 安装方法

正式上架后，可直接在思源笔记集市中安装并启用。

开发和本地测试时，执行构建命令，将 `package.zip` 内的文件解压到：

```text
{思源工作空间}/data/plugins/siyuan-notebook-groups/
```

注意：`plugin.json` 和 `index.js` 应直接位于上述插件文件夹内，不要多套一层 `dist`。覆盖安装后请重启思源笔记。

## 开发与贡献

开发环境需要 Node.js 和 pnpm。在项目根目录运行：

```bash
pnpm install
pnpm run build
```

编译后会生成 `package.zip`。主要功能代码位于 `src/index.ts`，插件配置位于 `plugin.json`。新功能的测试步骤详见 [TESTING.md](./TESTING.md)。

**欢迎其他开发者共同维护！** 可以通过 GitHub Issues 反馈问题、提出新功能，也可以通过 Pull Request 提交修复和改进。修改文档树相关代码后，建议测试分组拖拽、排序、文档展开、禁用插件以及重启后的恢复情况。

## 兼容性说明

插件通过调整思源笔记原生文档树的 **DOM 结构** 实现分组，并非使用思源官方提供的笔记本分组 API。因此，思源升级后若文档树结构发生变化，插件可能需要相应适配。

目前主要在 **Windows 桌面界面** 中进行开发测试。**移动端在原生文档树的笔记本行上增加分组标题和手柄，通过 CSS 视觉排序而不重排原生笔记本 DOM**；该适配尚需 Android/iOS 真机验证。若思源修改移动端树形界面结构，本功能可能失效。

## v0.2.0 测试提示

本次改版**取消独立的手机分组弹窗**，将分组放进思源移动端原生「文档」树。在文档树顶部提供「管理分组」，笔记本行不再显示分组下拉框；长按 ⠿ 拖动归类或排序。空分组显示在列表顶部辅助区域；没有成员的「未分组笔记本」显示在列表末尾。Android / iOS 真机操作尚未验证，请勿直接发布集市。

不同设备上的分组关系由插件数据存储；如果电脑与手机未配置思源同步，手机不会自动继承电脑端的分组设置。
